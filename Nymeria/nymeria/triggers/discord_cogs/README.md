# discord_cogs/

Discord slash command cogs. Each cog handles a related group of commands.

## Contents

- `chat.py` — `/chat` command, message handling
- `todos.py` — `/todo` commands
- `config.py` — `/config` commands
- `tools.py` — `/tools` commands
- `memory.py` — `/memory` commands
- `info.py` — `/info`, `/help` commands
