# discord_cogs/

Discord slash command cogs. Most commands are GENERATED from the backend
command registry; the hand-written cogs keep only what a defer-and-relay
wrapper cannot express.

## Contents

- `generated_cogs.py`  -  generated by `scripts/generate_discord_cogs.py` from
  the registry's declared params. Do not edit by hand; regenerate.
- `autocomplete.py`  -  `choices_ref` autocomplete resolvers, shared by the
  generated cog and `tools.py`
- `chat.py`  -  `/ask`, `/clear`, `/compact`, `/stop`, message handling
- `config.py`  -  `/restart` (the bot self-restart branch)
- `tools.py`  -  `/tools` group (kept for the Discord-local `/tools search`)
- `memory.py`  -  `/notepad` group (kept for `/notepad write`'s mode prefix)
- `info.py`  -  `/thread`, `/export`, `/channel-context`, `/show-tools`, `/help`
- `hooks.py`  -  `/hook` group
- `fallback.py`  -  `/fallback` group (model-swap consent)
